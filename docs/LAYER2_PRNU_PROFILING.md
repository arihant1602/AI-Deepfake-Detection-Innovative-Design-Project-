## Overview

Every physical CMOS camera sensor exhibits a unique, microscopic **Photo-Response Non-Uniformity (PRNU)** noise pattern, akin to a physical digital fingerprint. This pattern arises from silicon substrate manufacturing tolerances during wafer fabrication. For any genuine camera sensor, this pattern remains **spatially stationary** across all frames recorded on its pixel grid.

Injected deepfakes, virtual webcam injection streams (e.g., via OBS, Android virtual cameras), and digitally rendered synthetic avatars **lack accurate, continuous PRNU**:
1. **Lack of Inter-frame PRNU Persistence**: Generative models synthesize video frames independently or introduce synthetic random noise, yielding zero inter-frame residual correlation.
2. **Sub-threshold Peak-to-Correlation Energy (PCE)**: Authentic sensor fingerprints produce a sharp delta peak on 2D circular cross-correlation surfaces ($PCE > 50\text{--}100$). Synthetically generated or injected video streams lack this spatial coherence, exhibiting flat cross-correlation surfaces ($PCE < 20$).
3. **Reference Fingerprint Mismatch**: When cross-correlated against an enrolled camera fingerprint (e.g., from Layer 1 hardware attestation or enrollment calibration), injected deepfakes fail both Normalized Cross-Correlation (NCC) and PCE tests.
4. **Noise Floor Suppression**: Generative diffusion and GAN models smooth high-frequency sensor noise floors in skin regions (cheeks, forehead).

## How it works

1. **Edge-Attenuated Noise Residual Extraction**:
   - For incoming frames $I_t$, an edge-preserving filter extracts high-frequency sensor noise residuals $W_t = I_t - F(I_t)$.
   - Structural scene contours (face boundary, eyes, mouth) are detected via smoothed Sobel gradients and dilated to strictly eliminate edge leakage into the residual.
   - Row and column zero-meaning eliminates readout banding and codec block artifacts.

2. **Sensor PRNU Estimation & Verification**:
   - **Mode A (Reference Fingerprint Matching / Attestation)**:
     If an enrolled camera reference fingerprint $K_{\text{ref}}$ is supplied (e.g. from Layer 1 hardware attestation), the module computes the 2D FFT cross-correlation surface, Normalized Cross-Correlation (NCC), and Peak-to-Correlation Energy (PCE):
     $$PCE = \frac{C(0,0)^2}{\frac{1}{|\Omega|} \sum_{(u,v) \notin \mathcal{N}} C(u,v)^2}$$
     Genuine captures filmed on that camera produce an unmistakable spike at $(0,0)$ ($PCE > 1000$). Injected streams fail with $PCE < 20$.
   - **Mode B (Autonomous Blind Consistency Analysis)**:
     If no reference fingerprint is available, the module performs split-half accumulation: odd frames and even frames are accumulated independently into $\hat{K}_{\text{odd}}$ and $\hat{K}_{\text{even}}$. In genuine camera video, both halves independently reconstruct the stationary physical sensor PRNU ($PCE > 50$). In injected deepfakes, the noise is uncorrelated between intervals ($PCE \approx 1\text{--}15$).

3. **Inter-Frame Persistence & Noise Floor Adequacy**:
   - Measures consecutive frame noise residual correlation across time on the pixel grid.
   - Evaluates face ROI noise variance to detect artificial skin smoothing from generative diffusion or GAN synthesis.

4. **Normalized Anomaly Scoring**:
   - Combines components into a single anomaly score in $[0, 1]$ with human-readable explanations.
   - Outputs standardized JSON matching the pipeline specification for Layer 5 Gated Fusion.

## Run it

### Prerequisites
```bash
pip install opencv-python-headless numpy scipy --break-system-packages
```

### 1. Autonomous Blind Analysis (No Reference Fingerprint Required)
```bash
python camera_sensor_noise_profiling.py --video path/to/clip.mp4
python camera_sensor_noise_profiling.py --video path/to/clip.mp4 --output result.json
```

### 2. Enroll Camera Sensor Fingerprint
Extract and persist a reference camera fingerprint from a trusted genuine calibration clip:
```bash
python camera_sensor_noise_profiling.py --video genuine_calibration.mp4 --enroll-ref my_camera.npy
```

### 3. Verification Against Enrolled Camera Fingerprint
```bash
python camera_sensor_noise_profiling.py --video clip.mp4 --ref-fingerprint my_camera.npy
python camera_sensor_noise_profiling.py --video clip.mp4 --ref-fingerprint my_camera.npy --output result.json
```

## Configuration and Tuning

All algorithmic thresholds live in the `CONFIG` dictionary at the top of `camera_sensor_noise_profiling.py`:
- `pce_authentic_thresh`: 45.0 (PCE threshold for genuine physical camera correlation)
- `ncc_authentic_thresh`: 0.05 (Normalized Cross-Correlation zero-shift threshold)
- `persistence_authentic_thresh`: 0.20 (Inter-frame consecutive residual correlation threshold)
- `score_flag_thresh`: 0.55 (Final aggregate anomaly threshold)
- `weights`: Relative component weighting for `inter_frame_persistence` (0.35), `pce_correlation_energy` (0.35), `normalized_cross_corr` (0.15), and `noise_floor_adequacy` (0.15).

## Integration note for Ramya / Layer 5 fusion

This module requires only a video file path (and optional reference `.npy` fingerprint path) and returns a JSON object.
It can be executed as a standalone CLI tool or imported directly in Python:
```python
from camera_sensor_noise_profiling import CameraSensorNoiseProfiler

profiler = CameraSensorNoiseProfiler()
result = profiler.analyze("session_stream.mp4", ref_fingerprint_path="enrolled_device.npy")

if result.flagged:
    print(f"Layer 2 Alert: {result.explanation}")
```

Per the IDP gated fusion architecture:
- If Layer 1 (Aarya's hardware attestation) provides a cryptographically attested sensor fingerprint, pass it to Layer 2 via `--ref-fingerprint`.
- If Layer 2 detects severe PRNU absence ($score \ge 0.55$), Layer 5 Gated Fusion can trigger early session termination or route to Layer 3 (Vibha's temporal & frequency analysis) for secondary confirmation.
